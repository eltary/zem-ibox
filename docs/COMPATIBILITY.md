# Совместимость

Требуется Android 7.0 или новее.

Zem iBox поддерживает семейство Jieli / DVRunning2. Пользователь проверил
**iBOX Flash WiFi Dual / AC54xx_wifi_car_camera, прошивка 1.0.1**.
Другие физические модели пока не проверены. Поддержка протокола не гарантирует
все функции оригинального приложения на каждой прошивке.

| Возможность | Поддержка |
| --- | --- |
| Управление устройством | CTP по TCP 3333, HTTP 8080 |
| Лайв H.264 / MJPEG | Jieli TCP 2229, UDP 2224/2225, RTSP |
| Звук | PCM Jieli; RTSP L16 8 кГц mono и G.711 в резервной аудиодорожке |
| Передняя и задняя камеры | Задняя включается вручную и проверяется по состоянию устройства |
| Качество | 640×480 / 1280×720 / 1920×1080 по возможностям прошивки; показывается фактическое разрешение |
| Архив | Список, фильтр, миниатюры, плеер, защита файла, скачивание с продолжением |
| Покадровый просмотр | Вперёд и назад на паузе, удержание для медленного просмотра; точный кадр получает системный декодер Android |
| Экспорт фрагмента локального видео | MP4 без перекодирования совместимых H.264/H.265/MPEG-4 и AAC/AMR; начало с предыдущего ключевого кадра |
| Запись на телефон | MP4 H.264/AAC; RTSP H.264 может сохраняться в MKV |
| microSD | Состояние, ёмкость, форматирование после отдельного подтверждения |
| Время устройства | Предложение синхронизации при расхождении более пяти минут |
| Удаление файлов / заводской сброс | Общие опасные команды заблокированы |
| Обновление прошивки, GPS, проекция, двусторонняя связь | Не реализованы |

## Выбор транспорта

Описание устройства содержит `net_type`, `rts_type`, `forward_support` и
`behind_support`. Массивы могут приходить как JSON-массивы или строки JSON.
`net_type=0` выбирает TCP, `1` — UDP; RTSP доступен вручную и по описанию камеры.
Профиль сохраняется для устройства, а не для марки из названия SSID.

RTSP использует пути DVRunning2 `264_pcm_rt/XXX.sd|hd|fhd` и
`avi_pcm_rt/front.sd|hd|fhd`; задняя камера — `rear`.
Если TCP не поддержан или за шесть секунд не даёт изображения, выполняется
один переход на UDP. Повторы не продолжаются бесконечно.

## Известные особенности

- iBOX пользователя может отдавать 1920×1080 при запросе 640×480. Ответ команды
  открытия потока не доказывает применение качества. Есть отдельный повтор
  после подтверждённой остановки записи на microSD; параметры самих оригиналов
  не меняются автоматически.
- Наличие `behind_support` не доказывает физическое наличие второй камеры.
- При отсутствии PCM Jieli приложение пробует отдельный аудиотрек RTSP без
  второго видеопотока. Если прошивка не даёт звук и там, запись сохраняется
  с предупреждением. Эта комбинация на конкретном физическом iBOX ещё проверяется.
- Просмотр по Wi-Fi ограничен скоростью сети регистратора. Для высоких скоростей
  воспроизведения лучше скачать оригинал.
- При циклических перезагрузках до подключения отправить форматирование нельзя.
